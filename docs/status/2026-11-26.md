## Fix (outside tools/ and docs/)

- `tier2-logic/worker/src/seed/tenant.ts` (DATA-08): each preset's seed changeset now runs the DOM-05
  `recomputeHook`, so every preset gets its `calc_run` (04 §2 step 6, ADR-007). Before, the seed used the
  default no-op recompute, so `GET /scenarios/:preset/calc` answered 404 ("make an edit to calculate it")
  for every preset forever, since a locked preset is never edited. New test in `seed.pg.test.ts`.
