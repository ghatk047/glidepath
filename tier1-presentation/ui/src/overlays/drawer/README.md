# overlays/drawer

Trace drawer and shared tooltip (UX inventory, Overlays). Presentational: every value arrives as a prop from tier 2 (web binds node ids); display text comes from `fmt`. Import as `@glidepath/ui/overlays/drawer`.

- `<TraceDrawer content onClose>`: right side, 420 px (`DRAWER_WIDTH_PX`), glass level 3. `content` is `{ title, value, nodeId, formula, upstream?, drivers? }`; `upstream` and `drivers` are `{ id, label, value }` lists (the upstream item whose id is `nodeId`, else the last, is highlighted). `content={null}` closes it (the last content stays while it slides out). Closes on Escape, on a press outside (`pointerdown`, except on `[data-node],[data-trace]` triggers; see `ignoreOutside`) and on the close button. Focus moves to the close button on open, Tab and Shift+Tab are trapped inside, focus returns to the trigger on close. `role="dialog"`, `aria-modal`. The glass surface unmounts after the exit slide so a closed drawer holds no blur slot.
- `<Tooltip />`: mount once at the app root. Glass level 3, 12 px, follows the pointer (offset and viewport margin derive from `space.gap`), clamped to the viewport. One shared instance: a second `<Tooltip />` renders nothing, so there is a single `role="tooltip"`. Charts drive it with `{...tipProps(content)}` on a mark (pointer enter/move/leave, focus/blur), or with `showTip(content, x, y)` / `hideTip()`. Any element with `data-tip="text"` gets a plain-text tip.
- CSS is generated from tokens (`styles.ts`) and injected with a React 19 hoisted `<style>`. Under `prefers-reduced-motion` the slide and fade are off.
