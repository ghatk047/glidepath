# overlays/palette

Command palette (#4, `openPalette`) and Edits counter + changeset tray (#5). Module `src/overlays/palette` (import `@glidepath/ui/overlays/palette`). Presentational only: the index, the changes and the can-undo flags arrive as props; ids are used verbatim (ADR-018: binding to node ids lives in web).

- `<CommandPalette open onOpenChange items onSelect suggestions shortcut placeholder>`: "Find any number". `items` is `PaletteItem[]` (`id`, `label`, `kind`, `unit?`) for inputs, levers, nodes, lines and screens. ⌘K / Ctrl+K calls `onOpenChange(true)` (set `shortcut={false}` if web owns the key). Up to 9 results (`MAX_RESULTS`), kind and unit on the right, arrows (wrap, Home, End) + Enter select, click selects. Matching is text only (`searchItems`: every typed word in label, id or kind, arrival order kept). Empty state: `No match. Try COLA, cloud or headcount.` (override with `suggestions`; a suggestion fills the query). Selecting calls `onSelect(item)` then `onOpenChange(false)`; focus that `onSelect` moved is not taken back.
- `<EditsTray count changes canUndo canRedo onUndo onRedo onSaveAsScenario onDiscard open? defaultOpen? onOpenChange? title?>`: the top-bar counter button ("● 3 edits", dot when `count > 0`) and the tray under it. `changes` is `EditChange[]` (`id`, `who`, `what`, `from`, `to`); the texts arrive formatted and are rendered as given. Undo / Redo are disabled by `canUndo` / `canRedo` and keep the tray open; Save as scenario and Discard call back and close it (and are disabled at count 0).
- Both are dialogs: focus moves in on open, Tab and Shift+Tab are trapped, Escape closes, focus returns to the opener. The palette is modal (`aria-modal`, focus pulled back in, scrim press closes, portalled to `<body>`); the tray closes on an outside press. Palette input is a combobox over a listbox (`aria-activedescendant`); a status region announces the result count.
- Styles: `paletteCss` (tokens only; the scrim is `color-mix` of the ground token) is mounted once by `usePaletteStyles()`, which also mounts the editable CSS for the shared `.gp-btn` / `.gp-chip`. Panels are level 3 `GlassPanel`s; mount `GlassProvider` at the app root.
